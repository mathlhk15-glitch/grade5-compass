# 경일 내신·학과 진학 나침반 2028

5등급 내신 평균 하나를 입력하면 다음 네 단계를 보여 주는 학생·학부모용 탐색 도구입니다.

1. 표본 기준 누적 위치
2. 과거 입결 비교 범위
3. 학과군별 대학·모집단위
4. 경일 선배 사례

**합격 예측기가 아닙니다.**

## 폴더 구성

| 파일 | 역할 | 수정 방법 |
|---|---|---|
| `index.html` | 화면과 계산 엔진. 판정 기준은 맨 위 `CONFIG`에 모여 있음 | 직접 수정 |
| `data/scale.js` | 부산·경기 5등급 분포와 9등급 대응표 | 3-1 자료가 나오면 값만 교체 |
| `data/majors.js` | 9개 계열 · 36개 학과군 · 동의어 · 분류 규칙 · 계열 팁 | 직접 수정 (핵심 DB) |
| `data/universities.js` | 전국 수시 입결(대학어디가 2023~2026) | 스크립트로 자동 생성 |
| `data/gyeongil_cases.js` | 창원경일고·경일여고 수시 지원 사례(집계) | 스크립트로 자동 생성 |
| `tools/build_data.py` | 위 두 데이터 파일 생성 | — |

데이터를 `.js`로 만든 이유는 GitHub Pages뿐 아니라 PC에서 `index.html`을 더블클릭해도 작동하게 하기 위해서입니다.

## 배포 (GitHub Pages)

1. 새 저장소(예: `gyeongil-compass-2028`)에 이 폴더 내용을 그대로 올립니다.
2. Settings → Pages → Branch `main` / root를 선택합니다.
3. lhk15 포털 `data.js`에 카드를 추가합니다.

## 데이터 갱신 (매년)

```bash
pip install openpyxl
python tools/build_data.py --adiga "대학어디가_수시입결.xlsx" --compass public_data.json --report
```

- `--adiga`: '대학자료' 시트가 있는 엑셀 파일. 열 이름: 지역, 대학, 연도, 수시/정시, 교과/종합, 전형, 학과, 인문/자연, 모집인원, 경쟁률, 추합, 등급50, 등급70, 소계열
- `--compass`: 수시나침반 저장소의 `public_data.json`
- `--min-year`: 최근 공개 입결이 이 연도 이상인 모집단위만 사용합니다. 기본값은 2025입니다.
- 자동 점검: 1.00으로 채워진 비공개값 제외, 50%·70% 역전 시 큰 값 사용, 같은 이름 모집단위(모집인원만 다름) 분리 표시, 원자료 Sheet2의 확인필요 대학 표시
- `--report` 출력에서 확인할 것:
  - **미분류 학과**가 나오면 `majors.js`의 `rules`에 키워드를 추가합니다. 목표는 0개입니다.
  - **전국 DB에 없는 대학명**이 나오면 `build_data.py`의 `UNI_SPECIAL`에 이름 대응을 추가합니다.

## 판정 로직 요약

- **위치:** 시점(1-1 / 1학년 누적 / 2-1까지)에 맞는 누적비 열을 쓰고, 백분위를 공통 축으로 삼습니다.
- **9등급 참고 범위:** 부산 값과 경기 값을 범위로 표시합니다. 1학년 시점은 범위를 넓힙니다(1-1: ±0.2, 1학년 누적: ±0.1).
- **판정 범위:** 참고 범위 ±0.05로 잡되, 폭이 0.4보다 좁으면 0.4로 넓힙니다. 대학 70%컷에는 ±0.1 버퍼를 둡니다.
- **경일 사례:** 입결 숫자를 보정하지 않고 증거 배지로만 씁니다. 지원 5건 미만이면 건수를 숨기고 "소수 사례"로 표시합니다.
- **제외 대상:**
  - 논술·실기 전형
  - 특별전형(기회균형, 농어촌 등)
  - 부울경 외 권역의 지역인재 전형

모든 기준값은 `index.html`의 `CONFIG`에 있습니다. **2028 대입 결과가 나오면 선배 결과로 역검증한 뒤 조정**하세요. 매칭 로직은 지금도 졸업생의 9등급 성적으로 검증할 수 있습니다.
