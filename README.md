# 경일 내신·학과 진학 나침반 2028

5등급 내신 평균 하나를 입력하면 다음 네 단계를 보여 주는 학생·학부모용 탐색 도구입니다.

1. 표본 기준 누적 위치
2. 과거 입결 비교 범위
3. 학과군별 대학·모집단위
4. 경일 선배 사례

**합격 예측기가 아닙니다.**

## 폴더 구성

| 파일 | 역할 | 수정 방법 |
|---|---|---|
| `index.html` | 화면과 계산 엔진. 판정 기준은 맨 위 `CONFIG`에 모여 있음 | 직접 수정 |
| `data/scale.js` | 부산·경기 5등급 분포와 9등급 대응표 | 3-1 자료가 나오면 값만 교체 |
| `data/majors.js` | 9개 계열 · 36개 학과군 · 동의어 · 분류 규칙 · 계열 팁 | 직접 수정 (핵심 DB) |
| `data/universities.js` | 전국 수시 입결(대학어디가 2023~2026) + 대학 공식 링크 | 스크립트로 자동 생성 |
| `data/gyeongil_cases.js` | 창원경일고·경일여고 수시 지원 사례(집계) | 스크립트로 자동 생성 |
| `tools/build_data.py` | 위 두 데이터 파일 생성 | — |

데이터를 `.js`로 만든 이유는 GitHub Pages뿐 아니라 PC에서 `index.html`을 더블클릭해도 작동하게 하기 위해서입니다.

## 배포 (GitHub Pages)

1. 새 저장소(예: `grade5-compass`)에 이 폴더 내용을 그대로 올립니다.
2. Settings → Pages → Branch `main` / root를 선택합니다.
3. lhk15 포털 `data.js`에 카드를 추가합니다.

## 데이터 갱신 (매년)

```bash
pip install openpyxl
python tools/build_data.py --adiga "대학어디가_수시입결.xlsx" --compass public_data.json --report
```

- `--adiga`: '대학자료' 시트가 있는 엑셀 파일. 열 이름: 지역, 대학, 연도, 수시/정시, 교과/종합, 전형, 학과, 인문/자연, 모집인원, 경쟁률, 추합, 등급50, 등급70, 소계열
- `--compass`: 수시나침반 저장소의 `public_data.json`
- `--min-year`: 최근 공개 입결이 이 연도 이상인 모집단위만 사용합니다. 기본값은 2025입니다.
- 자동 점검: 1.00으로 채워진 비공개값 제외, 50%·70% 역전 시 큰 값 사용, 같은 이름 모집단위(모집인원만 다름) 분리 표시, 원자료 Sheet2의 확인필요 대학 표시
- 연도 연결: 가운데점·공백·하이픈 등 표기만 다른 같은 전형·학과는 하나로 묶어 최근 3개년 추이를 연결합니다. `(야)/(주)/(인문)/(자연)` 등 의미 있는 구분은 유지합니다.
- `대학링크` 시트가 있으면 입학처·대학 발표 입결·대학어디가 링크를 함께 가져옵니다.
- `--report` 출력에서 확인할 것:
  - **미분류 학과**가 나오면 `majors.js`의 `rules`에 키워드를 추가합니다. 목표는 0개입니다.
  - **전국 DB에 없는 대학명**이 나오면 `build_data.py`의 `UNI_SPECIAL`에 이름 대응을 추가합니다.

## 판정 로직 요약

- **위치:** 시점(1-1 / 1학년 누적 / 2-1까지)에 맞는 누적비 열을 쓰고, 백분위를 공통 축으로 삼습니다.
- **9등급 참고 범위:** 부산 값과 경기 값을 범위로 표시합니다. 1학년 시점은 범위를 넓힙니다(1-1: ±0.2, 1학년 누적: ±0.1).
- **판정 범위:** 참고 범위 ±0.05로 잡되, 폭이 0.4보다 좁으면 0.4로 넓힙니다. 대학 70%컷에는 ±0.1 버퍼를 둡니다.
- **전국 입결:** 기본 비교값은 모집단위별 가장 최근 공개연도의 70%컷(현재 자료에서는 주로 2026학년도)을 사용합니다. 카드에는 2024~2026 최근 3개년 70%컷을 함께 보여 줍니다.
- **경일 사례:** 입결 숫자를 보정하지 않고 증거 배지로만 씁니다. 지원 5건 미만이면 건수를 숨기고 "소수 사례"로 표시합니다.
- **제외 대상:**
  - 논술·실기 전형
  - 특별전형(기회균형, 농어촌 등)
  - 부울경 외 권역의 지역인재 전형

모든 기준값은 `index.html`의 `CONFIG`에 있습니다. **2028 대입 결과가 나오면 선배 결과로 역검증한 뒤 조정**하세요. 매칭 로직은 지금도 졸업생의 9등급 성적으로 검증할 수 있습니다.

## 화면 기능 (v1.2)

- **최근 3개년 입결:** 대학 탐색 카드에 2024·2025·2026학년도 70%컷을 함께 표시합니다. 대학 비교 판정에는 가장 최근 공개연도의 값을 사용합니다.
- **연도별 동일 모집단위 연결 강화:** `화공・생물공학부` / `화공ㆍ생물공학부`처럼 문장부호만 다른 명칭은 하나의 추이로 연결합니다. 야간·주간·인문·자연 등 의미 있는 구분은 합치지 않습니다.
- **지역인재 자격 확인:** 부울경 지역인재도 카드에 `자격확인`을 표시하며, 실제 모집요강의 고교 소재지·재학기간 조건을 확인하도록 안내합니다.
- **데이터 품질 정렬:** 원자료에서 `확인 필요`로 표시된 자료는 같은 학과군·구간 안에서 일반 자료보다 뒤에 배치합니다.
- **공식 링크:** 엑셀의 `대학링크` 시트를 이용해 가능한 경우 카드에서 입학처·대학 발표 입결·대학어디가로 바로 이동할 수 있습니다.
- **유사 학과 경일 사례 상세:** 정확히 같은 학과의 경일 사례가 없을 때, 같은 대학·같은 학과군의 실제 유사 학과 사례를 펼쳐 확인할 수 있습니다.
- **즐겨찾기 3개년 비교:** 골라둔 모집단위 표에도 최근 3개년 70%컷을 함께 표시합니다.

### v1.1부터 유지되는 기능

- **학생부교과 기본, 학종은 선택:** 결과는 기본적으로 학생부교과만 보여 줍니다. '📘 학종 함께 보기'를 누르면 학생부종합도 표시됩니다.
- **경일 사례만 있는 모집단위 분리:** 공식 입결이 없는 모집단위는 '🏫 공식 입결은 없지만 경일 선배 사례가 있어요' 별도 목록에 모았습니다.
- **입결 연도 배지:** 카드마다 '2026 입결'처럼 연도를 표시합니다. 최신 연도가 아니면 '이전연도 참고'를 붙입니다.
- **검색 보조:** 검색창 자동완성(동의어·학과군 이름)과 '🔗 함께 볼 만한 학과군' 확장 버튼이 있습니다.
- **골라두기:** ☆를 누르면 모집단위가 저장되고 비교표로 볼 수 있습니다. 이 기기의 브라우저(localStorage)에만 저장되며 어디에도 전송되지 않습니다.
- **공유 링크:** '🔗 이 결과 공유하기'를 누르면 성적 시점, 평균, 학과군, 지역, 전형 조건을 담은 URL이 만들어집니다. 이름과 학번은 들어가지 않습니다.
- **📈 성적을 조금 올리면?:** 평균이 0.1·0.2 좋아졌을 때의 위치와 '비슷한 구간' 모집단위 수를 보여 줍니다.
- **입력 기준 선택은 교사용:** 전과목/국영수사과 선택은 자세히 보기에서만 나타납니다. 빠르게 보기는 국영수사과 평균 기준입니다.
- **학교별 사례:** 자세히 보기에서 경일고와 경일여고 사례를 따로 표시합니다. 학교별로도 5건 미만이면 건수를 숨깁니다.
- **관리자 진단:** 주소 끝에 `?debug=1`을 붙이면 데이터 점검표가 나타납니다. 미분류, 의심 분류, 역전, 동명 분리, 확인필요, 대학명 불일치 등을 보여 줍니다.
